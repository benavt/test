# Neon Snake

A lightweight, zero-dependency arcade snake game built with vanilla HTML, CSS, and HTML5 Canvas.

## Features

- Smooth neon glow visuals and particle bursts
- Progressive speed scaling as your score climbs
- Synthesized retro Web Audio sound effects (with mute toggle)
- Toggleable **Solid** vs **Wrap-around** walls
- Local high-score persistence (`localStorage`)
- Keyboard (`Arrow Keys` / `WASD`, `Space` to pause) and mobile touch D-pad controls

## Play

Play online via GitHub Pages: **https://benavt.github.io/test/**

Or play locally (no build step or dependencies required) — just open `index.html` in your browser:

```bash
open index.html
```

Or serve it with any static file server:

```bash
python3 -m http.server 8000
```
